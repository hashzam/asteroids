The mission

A modern rebuild of the 1979 arcade classic — written from scratch in Python with pygame. Newtonian thrust, escalating waves, and hostile UFOs that shoot back.

🌊

Wave system

Each cleared wave adds another asteroid and cranks the speed up 10%. Survive as long as your reflexes allow.

🛸

Hunter UFOs

Large and small saucers cruise in and open fire. The small one is worth 1000 points — if you can hit it.

⚡

Power-ups

Shields and rapid fire drop from wreckage. Triple your fire rate or shrug off a hit.

🚀

Real physics

Momentum-based thrust with drag and a top speed. You don't steer — you accelerate.

✨

Particle FX

Explosions, thruster trails, and a parallax starfield bring the vector look to life.

🏆

High scores

Your best run is saved to disk. Three lives, brief invincibility on respawn — make them count.

Scoring

Smaller targets are worth more. Break the big rocks down and pick off the saucers.

Play it

Clone the repo and launch. You'll need Python 3 — the project uses uv to manage dependencies.

# grab the code
git clone https://github.com/hashzam/asteroids.git
cd asteroids

# run it (uv installs pygame for you)
uv run main.py

# ...or with plain pip
pip install pygame
python main.py
